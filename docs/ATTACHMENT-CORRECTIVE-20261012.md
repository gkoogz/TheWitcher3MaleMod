## Reproduction

verified graft archive, SHA256
`29fcb57c4b3da7b1bcdb40577855fe05ab0c60d00831cc3efddf98453d67d0d3`.
The binding remains at `431e626cae6fb6720b552f8b20206727fe809c80`.
Source implementation revision/hashes are recorded independently; the dirty

Build with `MALEMOD_ENABLE_ATTACHMENT_CORRECTIVE=ON`. Generate reviewed private
fields using `build_collar_corrective.py --base <explicit Base checkout>
--recipe <private recipe> --output <private native directory>/geralt.corrective`.
The recipe binds source output, material domains and reviewed knots for both
LODs. Artifact v3 contains binding checksum, geometry revision, per-LOD depth,
body frame, exclusions, frame weights and knots. Changing source geometry or
bindings requires a new field and review.

Use `prepare_collar_session.py --root-review` and `run_iteration_world.py` with
the repository-owned preview. Close by exact receipt. Checkpoints 75/82/83 dump
source output and both target LODs for same-frame preservation comparisons.
