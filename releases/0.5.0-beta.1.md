# 0.5.0 Beta 1 — native anatomy runtime

This beta publishes the installed October 3 checkpoint, runtime source commit
`a221d34`, with MaleModBase pinned to
`2a7b38a7019d6102046085a8586e86273d5579fe`.

## Included

- Complete native DX12 runtime and the required cooked rig/body resources.
- All 18 source anatomy/physics controls in the separate F6 overlay. Arrow keys
  select/adjust; Shift increases the step.
- Shared numerical physics, progressive radial pelvic recruitment and coupled
  torso/lower-body waist bindings in both native LODs.
- Detailed skin textures with deterministic Geralt color/material matching.
- Corrected final-vertex GPU lighting bounds; rear black patch fixed on AMD.
- Source clinical timing, ambient modes, liquid and actual scene floor deposits.
  Future dialogue slots remain silent; no private audio is distributed.

The install archive includes its own installer, upgrade, uninstall, rollback,
manifest and checksums. REDkit, Python and a separate earlier mod download are
not required for installation. Source and development tools remain on GitHub.

## Verification and limits

The exact installed DLL is
`879972cf06e2a6abca7b74ae3498085eac6e936c1c69cc0f3020f027eac8d216`.
Twenty ordered private gameplay checks, 73 adapter Python tests, 11 native
tests, actual AMD/WARP final-vertex tests, 39 source/body cases and 28 radial
states passed. The delivery certificate records hashes and evidence separately.
Displayed interpolation cadence is not numerical solver throughput or game FPS.
Ray tracing and distant LOD transitions have not been observed.

The user's post-checkpoint review identifies these follow-ups: extreme rest
angles can tilt the recruited collar; fluid phase appearance and terminal pump
ground marking need correction; menu labels should match Wolverine. These are
known beta issues, not silently claimed fixed by this release. Optional shared
jockstrap clothing is planned next. Wolverine is unchanged in this release.
